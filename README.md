# Sabanci Pharmacy E-commerce Website

Welcome to the **Sabanci Pharmacy E-commerce** repository. This project is a full-stack application designed to manage pharmacy operations, consisting of a modern React frontend and a robust Spring Boot backend.

## 📂 Project Structure

The project is organized into two main modules:

### 🖥️ [Frontend](frontend/)

The user interface is built using **React**, **TypeScript**, and **Vite**. It features a responsive design using **Tailwind CSS**.

  * **📖 Documentation**: [frontend/README.md](frontend/README.md)
  * **Key Features**:
      * Product browsing and searching
      * Shopping cart and checkout flow
      * User authentication (Login/Register)
      * Order history tracking

### ⚙️ [Backend](backend/)

The server-side application is built with **Spring Boot** and **Java**. It handles API requests, database interactions, and business logic.

  * **📖 Documentation**: [backend/HELP.md](backend/README.md)
  * **Key Features**:
      * RESTful API endpoints
      * Spring Security integration (JWT)
      * Database management with JPA/Hibernate
      * Order and product management services

## 🚀 Getting Started

To get the application running locally, please refer to the specific setup guides in each directory:

1.  **Frontend Setup**: Follow the instructions in [frontend/README.md](frontend/README.md) to install dependencies and start the dev server.
2.  **Backend Setup**: Follow the instructions in [backend/README.md](backend/README.md) to configure the database and run the Spring Boot application.
